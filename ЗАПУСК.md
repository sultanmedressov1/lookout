# TrustLink — Инструкция запуска

## Шаг 1: Supabase (база данных)

1. Идёшь на https://supabase.com → создаёшь новый проект
2. Называешь проект "trustlink"
3. Запоминаешь пароль (он нужен будет)
4. Ждёшь ~2 минуты пока создаётся
5. Идёшь в **SQL Editor** (левое меню)
6. Открываешь файл `supabase/schema.sql` из проекта
7. Копируешь весь текст → вставляешь в SQL Editor → нажимаешь **Run**
8. Должно написать "Success" — база создана ✓

**Забираешь ключи:**
- Settings → API → копируешь:
  - `URL` → это `NEXT_PUBLIC_SUPABASE_URL`
  - `anon public` → это `NEXT_PUBLIC_SUPABASE_ANON_KEY`
  - `service_role` (secret) → это `SUPABASE_SERVICE_ROLE_KEY`

## Шаг 2: Проект на компьютере

Убедись что установлен Node.js (https://nodejs.org → скачай LTS версию)

```bash
# В терминале (PowerShell или CMD):

# Переходишь в папку где хочешь хранить проект
cd C:\Users\user\Desktop

# Копируешь проект
# (у тебя уже есть папка trustlink с файлами)

cd trustlink

# Создаёшь файл с ключами (копируешь из .env.local.example)
copy .env.local.example .env.local
# Затем открываешь .env.local и вставляешь свои ключи из Supabase

# Устанавливаешь зависимости
npm install

# Запускаешь
npm run dev
```

Открываешь http://localhost:3000 — видишь сайт ✓

## Шаг 4: Деплой на Vercel

1. Создаёшь аккаунт на https://vercel.com
2. Заливаешь код на GitHub (создаёшь репозиторий)
3. В Vercel → Import Project → выбираешь репозиторий
4. В настройках добавляешь Environment Variables (те же что в .env.local)
5. Deploy → сайт живёт на yourproject.vercel.app ✓
